# restaurant-menu
🍽️ Dream Dine – Food Delivery App UI
Welcome to Dream Dine, a sleek and vibrant mobile application UI designed for a seamless and appetizing food delivery experience.

📱 Overview
Dream Dine is a food delivery app UI that offers a user-centric interface, visually rich food presentation, and intuitive navigation. The design focuses on simplicity, bold color usage, and engaging call-to-actions to enhance user engagement and ease of use.

📂 Screens Included
Splash Screen

App branding with logo and name.

Bold red background for strong visual identity.

Welcome Screen

Introductory message with food-themed background.

“Get Started” CTA to encourage user onboarding.

Home Screen

Personalized greeting and delivery location.

Search bar for food or restaurants.

Promo banner (e.g., 30% off on Shrimp Noodles).

Category chips (Biryani, Noodles, Desserts).

Popular food carousel with quick info (price, rating, delivery time).

Food Details Screen

Detailed view of a selected item (e.g., Hyderabadi Biryani).

Add to cart functionality with quantity selector.

Size options (Small, Half, Full).

Description and similar dishes section.

CTA buttons: “Add to Cart” and “Order Now”.

🎨 Design Highlights
Color Scheme: Warm red tones for CTAs and branding; soft gradients for background.

Typography: Clean, modern sans-serif fonts with clear hierarchy.

Imagery: High-quality food images used throughout for visual appeal.

User Experience: Designed for fast browsing, easy ordering, and visual clarity.

🛠️ Tools Used
Figma for UI/UX design

Vector & raster assets for icons and images

This UI is ideal for:

Mobile food delivery startups

UX/UI case studies

Prototyping food ordering applications
